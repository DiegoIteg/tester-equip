# Processo de trabalho — Equipa de Testes

1. **Âmbito** (Hélder): o que testar, ambiente (Go Auto: testes), critério de "passa/não passa".
2. **Mapa de testes:** tudo o que há para clicar, preencher e integrar.
3. **Execução** pelos especialistas, cada falha com passo a passo, esperado, obtido, gravidade, print.
4. **Relatório + veredicto** "Pode publicar / Não pode publicar".
5. **Reteste** depois da correção + teste de fumo.

**Regra de ouro:** nada que envie, pague ou apague dados reais corre em produção; login sempre pelo Diego; nada se publica sem o "sim".
