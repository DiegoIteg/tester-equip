# Protocolo de Conversa da Equipa de Testes

> Cada projeto tem `projetos/<projeto>/conversa.md`, onde se pedem coisas, se entregam falhas, se decide. Antes de começar, cada agente lê o que lhe foi dirigido; no fim, escreve o que fez e a quem passa.

## 1. Formato de cada mensagem
```
### AAAA-MM-DD HH:MM · De: <Nome> → Para: <Nome(s) | Equipa | Diego>
**Tipo:** Pedido | Falha | Entrega | Pergunta | Opinião | Discordância | Decisão | Veredicto
**Assunto:** …
Texto curto. Ficheiros: `…`
**Próximo passo:** quem faz o quê, até quando.
```

## 2. Reuniões (na conversa.md)
| Reunião | Quando | Quem | Resultado |
| :--- | :--- | :--- | :--- |
| **Âmbito** | No início | Hélder (abre) + Diego | O que testar, ambiente, "passa/não passa" |
| **Execução** | Mapa pronto | Beatriz, Diogo, Mónica, Rafael, Lara | Falhas registadas |
| **Veredicto** | Testes feitos | Hélder consolida → Diego | "Pode / Não pode publicar" |
| **Reteste** | Correção feita | Quem achou confirma | Fechado / Reabrir |

## 3. Regras
- Formato de falha sempre: passo a passo, esperado, obtido, gravidade, print.
- Nunca publicar/pagar/enviar/apagar sem o "sim" do Diego.
- Nunca palavras-passe na conversa.
