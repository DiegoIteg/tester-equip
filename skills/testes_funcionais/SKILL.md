# Testes Funcionais

## Passos
1. Mapa: páginas/ecrãs, ligações, botões, formulários, integrações (`mapa_de_testes.md`).
2. Ligações: todas (sem 404), `tel:`, `mailto:`, WhatsApp, redes da marca, PDFs.
3. Formulários: obrigatórios, validações, mensagens PT-PT, envio com dados de teste, chegada.
4. Fluxos completos e estados (vazio/carregar/erro/sucesso).
## Formato de falha
Passo a passo · Esperado · Obtido · Gravidade (Crítico/Importante/Menor) · Print. Em `relatorio_de_testes.md`.
## Nunca
Produção com ações que mudam dados reais; dados reais; publicar sem o "sim".
