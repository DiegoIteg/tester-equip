# Skills da Equipa de Testes
- `testes_funcionais` — ligações, botões, formulários, fluxos, estados.
- `testes_automaticos` — Playwright, back-end/API, suite do Go Auto, regressão.
- `compatibilidade_e_desempenho` — dispositivos, navegadores, Lighthouse, tempos.
- `acessibilidade` — WCAG AA, estados, dados de teste fictícios.

## Ferramentas de topo (2026-10-11)
- `ferramenta_playwright` — testes de ponta a ponta no navegador (o mais usado).
- `ferramenta_axe_pa11y` — acessibilidade automática (axe-core + Pa11y).
- `ferramenta_lighthouse` — desempenho, SEO e boas práticas (Lighthouse + CI).
- `ferramenta_k6` — carga e stress (só em testes).
- `ferramenta_api` — testes de API (contrato, coleções, pedidos).
