# Acessibilidade

## WCAG AA
Contraste, teclado, foco visível, textos alternativos, etiquetas nos formulários, leitor de ecrã.
## Estados e dados
Estados vazio/erro com mensagens claras em PT-PT. Dados de teste fictícios (nome, NIF, morada de teste); nada real; sem dados de exemplo numa entrega final.
