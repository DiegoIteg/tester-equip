# Equipa de Testes do Diego

6 agentes que testam qualquer projeto do Diego (Go Auto, Agência Digital, clientes da iTEG): ligações, botões, formulários, integrações, telemóvel, velocidade, acessibilidade e back-end. Entregam um relatório de falhas (Crítico/Importante/Menor) e um veredicto "pode / não pode publicar".

Começar por ler: `CLAUDE.md` → `memory.md` → `equipa/README.md` → `equipa/protocolo_de_conversa.md` → a pasta do projeto em `projetos/<projeto>/`.

**Regras:** nada que mude dados reais corre em produção; login sempre pelo Diego; nada se publica sem o "sim".
